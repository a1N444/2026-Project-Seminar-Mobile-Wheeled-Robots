# Практика 3. Одометрия

Кузнецов Ярослав Сергеевич, вариант 7.

## Запуск

Команды выполняются внутри контейнера курса, где уже настроены ROS2 и Webots:

```bash
cd ~/practices_ws
colcon build --symlink-install --packages-select odometry_practice
source install/setup.bash
cd src/practice-03
ros2 launch odometry_practice spawn_robot.launch.py noise:=0.1 duration:=100.0 mode:=fast
```

В `noise` можно указать `0`, `0.02` или `0.1`. Launch сам выбирает сцену с нужным `encoderNoise`, запускает робота и сбор данных. Результаты появляются в папке `results`, после чего симуляция закрывается. Для обычной скорости воспроизведения вместо `mode:=fast` укажите `mode:=realtime`.

Во всех трёх экспериментах: скорости — 0.2 м/с и 0.2 рад/с, длительность — 100 секунд симуляции. Это примерно 3.2. Множитель базы `wheel_separation_multiplier` оставлен равным 1.1, как в примере.

## Результаты

Сравниваются истинная поза, одометрия по энкодерам и расчёт по командам. Обе позы из TF берутся в системе `map` на общее время. Расчёт по командам один раз получает начальную позу из GT, затем работает самостоятельно. Ошибка положения — расстояние до GT, ошибка угла считается с учётом перехода через ±π.

Без шума конечная ошибка положения по энкодерам получилась около 7.3 см. При шуме 0.02 рад итог почти такой же, но график становится неровнее. При 0.1 рад колебания заметно сильнее, особенно у ошибки угла; конечная ошибка положения — около 8.1 см. Шум не обязан увеличивать ошибку в каждой отдельной точке.

Траектория по командам почти не меняется между запусками: шум энкодеров в её расчёте не участвует. К концу ошибка положения составляет около 10.1 см. Она предполагает идеальное выполнение команд, а реальное движение в симуляции немного отличается. Поэтому расхождение есть даже без добавленного шума.

В `results` для каждого запуска лежат изображение с графиками и CSV с собранными данными.
